# V30 postmarketOS

**简体中文** | [English](README.en.md)

面向 LG V30 US998 的非官方、实验性 postmarketOS 集成项目与重建说明，采用横屏 TTY 文本界面。

本项目建立在 **postmarketOS、Linux 和 ShapeShifter499 的 V30 主线移植工作**之上。IMS 协议与媒体实现来自 **Catcrafts imsd**。我们的新增工作包括组件集成、开机顺序、每次通话的音频资源管理与清理、短信持久化、来电提醒与铃声音量、通话记录和常驻通知、普通音量与蜂窝状态栏、部分互操作修复，以及限定范围的验证。上游贡献与许可证信息见[致谢](ACKNOWLEDGEMENTS.md)和[来源记录](PROVENANCE.md)。

**验证结论仅适用于具体版本与测试范围。** 历史 r35/r36 结果来自一台使用中国联通网络的 US998。主机端的重建／打包检查与实机观察分别记录；部分 r37/r38 用户空间变更及后续修订的范围见下文。完整公开源码尚未在干净设备上重新完成端到端部署；较新内核候选也尚未在实机启动。Ready for review 仅表示 PR 已进入可评审阶段，不代表上游接受或实机验收通过。

我们的已完成工作及其上游基础集中记录在[贡献说明](docs/contributions.md)中；服务器稳定性、振铃与显号、短信完善及后续验证工作见 [TODO／路线图](TODO.md)。每项待办均附验收条件，在取得证据前保持未完成状态。除本中文 README 外，其余项目文档和命令行消息目前为英文。

## 来电与通知

r37 为横屏 TTY 增加以下功能：

- 来电振铃、自动亮屏和显号；缺失或不安全的号码显示为 `Unknown/withheld`，结束后清除当前来电行。
- 铃声音量可设为 0–100%，默认 60%，状态栏显示 `RING 60%`；0 为静音，来电仍可亮屏显号。
- 本地持久通话记录，区分已接、未接、拒接及证据不足的未知状态。
- `MISSED n   SMS n` 常驻计数，保留到相应标记被显式处理，不随当前来电行过期。

```sh
sudo v30-phone ring-volume
sudo v30-phone ring-volume 100
sudo v30-phone history --missed
sudo v30-phone history --missed --mark-read
sudo v30-sms list --unread
sudo v30-sms read ID
```

只查看通话列表不会清除通知；`--mark-read` 仅清除本次列出记录的标记，保留历史。读取短信会清除其本地未读标记，不会自动回复。音量百分比控制下一次来电的有限幅度铃声，不表示通话音量或实际声压。部署时将提醒模块、媒体包装器、状态栏、命令和配置一起安装，详见[来电、音量、记录和通知说明](docs/incoming-alerts.md)。默认方案保留正常登录认证和蓝牙关闭，不自动接听或拨号。

## 音量与蜂窝状态栏（r38）

- **`RING` 铃声音量：** 已在验收设备保存为 100%，用于下一次来电；通用配置示例仍默认 60%。百分比控制有限幅度的铃声，不改变通话增益。
- **`VOL` 普通扬声器音量：** 仅读取 ALSA 播放控制值；实机 8/15 显示为 53%，不代表实测声压。
- **`CELL` 当前运营商：** 使用当前注册网络的名称，名称为空时回退到网络代码；已检查联通 `UNICOM` 显示。
- **`NET` 当前网络制式：** 使用基带当前报告，实机显示 `4G LTE`。解析器可识别 2G/3G/4G/5G 报告，但 V30 硬件最高支持 4G，不具备 5G 能力。
- **`SIG` 信号状态：** 四格与质量百分比；旧读数保留最后格数并标注 `STALE`，缺失读数显示 `???? --`，搜索或无服务状态明确显示。

保留纯 TTY 横屏、正常登录认证、蓝牙关闭以及常驻未接来电／未读短信通知，最多占用五行状态栏。实机已检查 120 列画面、服务健康和保护文件；新增六项测试使 Linux root 测试总数达到 63 项。没有重新做 100% 铃声听验、语音／短信或重启验收。实现、输入能力说明与验证范围见[状态栏说明](docs/console-status.md)及 [r38 验证记录](provenance/r38-validation.json)。

## 版本路线

- **历史 r35/r36 重建输入：** 位于 `baseline/kernel/`、`runtime/` 和 `patches/imsd/`，固定版本见 [sources.lock.json](sources.lock.json)。旧内核基于 `1b42626…`，本地版本为 `7.2.0-rc2-v30-r30`，包含麦克风 MCLK 路由与 r35/r36 用户空间。后续公开版本的调整不能直接沿用历史实机通过结论。
- **较新的上游候选：** 位于 `patches/current-kernel/`，对应[内核 PR #12](https://github.com/ShapeShifter499/linux-lg-v30-joan/pull/12)，基于 `dc9c669…`。四个受影响目标文件已编译，但尚未构建完整内核镜像或在实机启动。[工具集 PR #11](https://github.com/ShapeShifter499/lg-v30-port/pull/11)公开短信工具和带版本限制的语音参考实现。截至 2026-10-31，两个 PR 均为 Ready for review，尚未合并。
- **部分 r37 用户空间新增功能：** `runtime/` 包含来电提醒、可调铃声音量、通话记录和常驻通知计数。[实机与主机端证据](docs/incoming-alerts.md)保留旧内核兼容性检查，不代表新镜像或重启验收通过。

- **r38 状态栏扩展：** `runtime/voice/console_status.py` 与控制台 metrics 显示独立音量、当前运营商、网络制式和信号；暂存安装包含新增模块。[检查点](provenance/r38-validation.json)固定实机安装源码哈希，不继承历史语音或重启验收结论。

历史快照保留了解释旧软件栈所需的诊断参数与兼容接口，应与清理后的上游补丁系列区分使用。`runtime/voice` 中的内核与硬件兼容性检查仍然保留。

## 开始使用

1. 阅读[架构与组件说明](docs/architecture.md)。
2. 按[构建与安装指南](docs/build-and-install.md)操作，并自行提供固件和设备配置。
3. 新部署时使用[验证与恢复清单](docs/validation.md)。通话和短信测试需要操作者明确执行。
4. 阅读[上游状态](docs/upstream.md)，区分上游已有修复、我们的变更和尚未向对应上游提交的补丁。

仓库包含源码、配置、构建辅助工具与重建说明。固件、已知可用的基础 boot／initramfs、凭据和文件系统 UUID 由操作者提供。仓库不包含整机镜像、私钥、原始短信归档、SIM 状态、私人备份或实际测试号码。

## 主机端检查

使用 Python 3.12 或更新版本。完整的 Linux 隔离测试还需要 PyGObject／Gio、D-Bus 和 util-linux：

```sh
python3 scripts/check.py
# Linux root: synthetic ModemManager on a private bus and network namespace.
unshare --net -- dbus-run-session -- sh -c \
  'export DBUS_SYSTEM_BUS_ADDRESS="$DBUS_SESSION_BUS_ADDRESS"; exec python3 "$1"' \
  qa runtime/sms/bench_private_bus.py
```

英文文档和命令行消息不会移除 Unicode 支持：测试中的合成中文／UCS2 载荷仍以转义字面量保留。
